# 新闻联播 NLP：从“关键词计数”到“注意力异常度”

这份文档说明 `policy_nlp.py` v2 的方法、字段和验证结果。

## 1. v1 的问题

| 问题 | 例子 | 后果 |
|---|---|---|
| 子串双计 | `新能源` 也命中 `能源`，`新能源汽车` 也命中 `汽车` | 能源长期被虚高 |
| 无否定语境 | “防范化解房地产风险” | 政策收紧被算成热度上升 |
| 分母是命中总数 | 某天只有 15 个命中，基建占 12 个 | 低基数日份额爆炸（80%） |
| 只有绝对分 | 没有基线 | 无法判断“今天算不算异常” |
| 关键词混入噪声 | `01`、`2026`、`发展` | 关键词表不可读 |

验证：在 187 个重叠日期上，v1 与 v2 的**头名行业有 71% 的天数不一致**，Top-3 平均只重合 1.73 个。

## 2. v2 的做法

### 2.1 最长匹配

```python
TERM_RE = re.compile("|".join(re.escape(t) for t in sorted(TERM_SECTORS, key=len, reverse=True)))
```

正则交替按词长倒序，「新能源汽车」整体消耗后，不会再单独匹配「汽车」「能源」。

一个词可以映射到多个行业：`新能源汽车 → [汽车, 新能源]`、`充电桩 → [新能源, 汽车]`。

### 2.2 否定语境

命中词前后 8 个字内出现 `防范 / 遏制 / 严禁 / 不得 / 整治 / 压减 / 严控 …`，记为 **负向命中**，进入 `sector_negative`，不计入注意力。

### 2.3 比喻语境排除

```python
TERM_EXCLUDE_CONTEXT = {
    "芯片": ("农业", "种子", "种质", "粮食", "饭碗"),
}
```

「农业的芯片」指种质资源，不算半导体。

### 2.4 注意力 = 提及该行业的新闻条数 / 当日总条数

```python
attention[s] = mentioned_articles[s] / news_count   # 0 ~ 1
```

多标签：一条新闻可以同时计入多个行业，所以各行业注意力之和可以大于 1。

### 2.5 滚动异常度

- `sector_z`：相对过去 30 个有数据日的 z-score（少于 5 天不计算）
- `sector_ema7`：7 日 EMA
- 历史完全平稳时，任何变化按 ±3σ 处理

### 2.6 事件判定

```python
z >= 3.0                                  → strong
z >= 2.0 且近两天 z >= 1.5                → watch（sustained）
attention < 0.15 或 z < 2.0               → 不报
```

加最低注意力门槛后，229 天里事件从 203 个降到 54 个（strong 36）。

## 3. 输出字段

保留 v1 的所有字段，新增若干：

```json
{
  "schema": 2,
  "date": "20261006",
  "news_count": 13,

  "sector_scores":   { "基建": 12 },            // v1 兼容：加权命中分
  "top_keywords":    [["算力", 0.034]],         // v1 兼容
  "items": [ ... ],                             // v1 兼容 + matched

  "sector_attention": { "基建": 0.3077 },       // 新增：覆盖率
  "sector_negative":  { "房地产": 3 },           // 新增：负向命中
  "sector_z":         { "科技": 4.27 },         // 新增：30 日 z-score
  "sector_ema7":      { "科技": 0.41 },         // 新增：7 日 EMA
  "events": [                                   // 新增：异常事件
    { "sector": "科技", "z": 4.27, "level": "strong", "sustained": false, "attention": 0.4545 }
  ],
  "top_keywords_textrank": [ ... ]
}
```

额外维护一份滚动序列：

```
data/policy/attention_series.json
{
  "updated": "2026-11-18T…",
  "days": [{ "date": "20261117", "attention": {...}, "z": {...} }]
}
```

只保留最近 120 天，滚动 z 只回看 30 天。

| Top-3 平均重合 | — | 1.73 / 3 |

## 6. 已知局限

1. **衡量的是宣传注意力，不是政策力度**。适合看边际变化，不适合直接当交易信号。
2. **多标签会抬高总量**。各行业注意力之和 > 100% 是正常的。
3. **行业词典仍有边界问题**：节假日客流新闻里的「铁路 / 公路 / 民航」会算进基建，但那是运营不是建设。
4. **z-score 对高频行业不敏感**：科技长期高位，只有明显跃升才会触发事件。
5. **关键词无法理解否定之外的反讽、条件句**。
